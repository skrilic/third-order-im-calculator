## Full Description

```text
Intermod RF Sites is a professional technical tool designed for RF engineers, radio communications technicians, network planners, and amateur radio operators to quickly analyze and calculate intermodulation products on collocated transmitter sites.

The app provides precise 3rd-order intermodulation product calculations (IM3 - 2f₁ - f₂, 2f₂ - f₁, f₁ + f₂ - f₃, etc.) alongside intuitive visual map overlays and interactive data grids.

KEY FEATURES:

🗺️ RADIO SITE MAP & LAYERS
• Visual map display of all saved RF locations and collocated transmitters.
• 3 selectable base layers: Standard vector map, High-resolution Satellite imagery (Esri World Imagery), and Topographic contour map (OpenTopoMap).
• Independent dark and light theme controls for both UI and map container.

⚡ PRECISE IM3 CALCULATIONS
• Calculate 3rd-order intermodulation products for any number of transmitters and frequencies.
• Ad-hoc manual calculator for quick field calculations with save-to-preset functionality.
• Link transmitters directly to GPS coordinates at specified locations.

🔍 ADVANCED DATA GRID & FILTERING (AG-GRID)
• Interactive results grid with fast multi-column sorting and filtering.
• Numeric frequency filter supporting range queries (e.g. 108.00 MHz to 135.50 MHz).
• Dual decimal separator support (both dot '.' and comma ',').
• Export calculated IM products directly to CSV for further analysis in Excel or reporting tools.

💾 DATA MANAGEMENT & GEOJSON IMPORT/EXPORT
• Import sites and transmitters from GeoJSON files with instant data preview.
• Complete JSON database backup export and import for device migration or safe keeping.

📴 100% OFFLINE & PRIVATE
• All data (locations, transmitters, calculations) is stored locally on your device (IndexedDB).
• No account creation, login, or external server required.
• Works seamlessly without an active internet connection.

LANGUAGES SUPPORTED:
• English
• Croatian

Streamline your RF site planning and interference troubleshooting with Intermod RF Sites!
```
